Sobre el proyecto

Inspirado en la clasica televisión de Los Simpsons y la epoca dorada de las tardes frente a la tele, este catalogo web consume datos mediante JavaScript y la API publica de TVMaze. Podras recorrer la grilla de programas, buscar tus favoritos por nombre o filtrarlos segun su genero.
